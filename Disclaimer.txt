### 📦 Step 4: How to Upload to GitHub

1. Go to [github.com](https://github.com) and log in.
2. Click the **"+"** icon in the top right corner and select **"New repository"**.
3. Name it `brain-tumor-ai` (or whatever you prefer).
4. Keep it **Public** (so your professor can see it) and click **"Create repository"**.
5. On the next page, look for the link that says **"uploading an existing file"**.
6. Open your `brain-tumor-ai` folder on your PC.
7. **Select all files EXCEPT `.env`** and drag them into the GitHub upload page. *(Note: If `brain_tumor_model1.h5` is larger than 25MB, GitHub might reject it. If that happens, you can upload it using Git LFS, or just exclude it from GitHub and mention in the README where it can be downloaded).*
8. Click **"Commit changes"**.
